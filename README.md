# The Royals - AI-Powered Wedding Hashtag Generator

> “From Regal to Reels — Hashtags for Every Kind of Love.”

The Royals is a stylish and smart Streamlit-based web app that generates creative, personalized wedding hashtags using the bride’s name, groom’s name, wedding vibe, and year — perfect for Instagram, reels, invites, and more!

---

##  Features

 **Vibe-Based Hashtag Generation**  
Get hashtags tailored to 5 different wedding moods:  
- Romantic  
- Royal  
- Fun  
- Desi  
- Elegant  

💍 **Two Styles of Hashtags:**  
- Trending Hashtags (based on names, year, and vibe)  
- Merged Name Hashtags (unique couple name blends like #RanAlia, #DeepVeer)

🎨 **Beautiful UI & Royal Theme**  
- Times New Roman font for elegance  
- Golden gradients, animations, and custom styling  
- Background image support for royal aesthetics

🖥️ **Streamlit Powered**  
Simple to run, fast to deploy, and fully customizable.
